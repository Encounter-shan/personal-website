## 这是什么

一个**单文件**的个人主页:所有 HTML、CSS、JavaScript 都写在同一个 `index.html` 里,
**没有任何框架、没有任何外部依赖**(不加载 CDN、不请求外部字体、不联网)。

双击 `index.html` 就能在浏览器里打开,不需要装环境、不需要起服务器。

## 实现了哪些功能

| 功能 | 说明 |
|---|---|
| **打字机标签** | 首屏的名字下面,标签逐字打出再逐字删除,循环轮播 |
| **滚动进场动画** | 每个区块滚动到视口时才淡入上移,只播一次 |
| **明暗主题切换** | 右上角按钮切换,选择记入本地,首次访问跟随系统偏好 |
| **移动端适配** | 窄屏自动变单列布局,导航折叠成汉堡菜单 |
| **阅读进度条** | 顶部有一条随滚动增长的进度条 |
| **导航高亮** | 滚动时自动高亮当前所在区块的导航项 |
| **回到顶部** | 右下角按钮,滚过一定距离后出现 |
| **无障碍支持** | 尊重系统的"减少动态效果"设置,关闭动画 |
| **打印样式** | `Ctrl + P` 时自动隐藏导航和按钮,适合导出 PDF |

## 页面结构

```
首屏 Hero  →  关于我  →  技能现状  →  项目与经历  →  备赛历程  →  联系我
```

## 技术要点

- **CSS 变量做主题切换**:`<html data-theme="light|dark">` 切换,只覆盖颜色变量,布局完全复用
- **`IntersectionObserver` 做滚动动画**:比监听 `scroll` 事件效率高
- **不引入外部字体**:用系统字体栈,保证断网也能正常显示、首屏不闪烁
- **单文件零依赖**:便于分发,也便于别人直接查看源码

## 本地查看

```bash
# 方式一:直接双击
index.html

# 方式二:起一个本地服务器(想换真人照片时推荐)
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> ⚠️ 关于换头像:如果想把 SVG 徽标换成真人照片,用 `file://` 直接打开时
> 浏览器**不允许网页读取本地图片**。这种情况需要起本地服务器,或者把图片转成 Base64 内联。
