关于我

About Me

我是文一行,武汉科技大学网络工程专业(国际学院)的学生。 目前我的主要编程语言是 C++,算法和数据结构的训练也围绕它展开 —— 从最基础的 vector 用法,到排序、前缀和、二分、动态规划, 都是一题一题做过来的。

我的习惯是先想清楚再动手:拿到一个问题,先看数据规模、 估一下复杂度能不能过,再决定用什么方法。这个习惯是被 C++ 逼出来的 —— 数组越界不会报错,整数除法会悄悄截断,这些坑踩过一次就记住了。

目前我在做两件事:一是为蓝桥杯系统训练算法, 二是跟着李鹏老师参与 2027 中国大学生工程实践与创新能力大赛 (虚拟仿真赛道 · 智能网联汽车设计),目前处于准备阶段,预计明年 4 月参加校赛。 前者练的是"把一个问题解对",后者练的是"在没有标准答案时把问题定义清楚" —— 两件事我都还在起步,但方向是清楚的。

我想加入 Java 俱乐部,动机很直接:我需要把 Java 真正补起来。 我学过面向对象程序设计,类、封装这些概念是懂的,但换成 Java 的语法还没实际写过,离"能独立写一个完整项目"还有距离, 而一个人自学最容易半途而废。我希望在一个有人一起写代码、 能互相看代码的环境里把这件事做完,同时也愿意在算法和刷题上帮到其他同学 —— 这一块是我现在确实能拿出来的东西。
